# Contributing

Keep changes within bounded, read-only Cargo cache diagnosis in
`docs/product-brief.md`. Do not add package installation, network access,
registry authentication, a GUI, a hosted service, or unrelated compatibility
claims.

Run the commands in `docs/release.md` for release changes. Review the diff and
exact validation output before committing. Never put credentials, private
paths, secret values, or generated fuzz corpus files in tracked content.
